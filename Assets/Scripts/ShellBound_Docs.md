# 🦀 מסמך תיעוד ארכיטקטורה וקוד - ShellBound (גרסה מעודכנת)

## 1. מבט על (Project Overview)
משחק פלטפורמה מבוסס פיזיקה (דו-ממדי) ב-Unity. השחקן שולט בסרטן המסוגל לאסוף קונכיות שונות המשנות את יכולותיו והפיזיקה שלו, לפתור חידות של דחיפה ומשיכה, ולשבור אובייקטים. התנועה מבוססת ארקייד (התאמת זווית ויזואלית לשיפועים), אך משתלבת עם אובייקטים פיזיקליים אורגניים.

## 2. ליבת השחקן (Player Core)
* **PlayerController.cs**: מוח השחקן. פיזיקה נעולה מסיבוב (`FreezeRotation`), אך ה-`visualsRoot` מסתובב ויזואלית כדי להתיישר עם הרצפה (`SurfaceNormal`). כולל מנגנוני Grab, זיהוי רצפה עם `CircleCast`, וניהול מגבלת משקל נדחף (`currentMaxPushMass`).
* **PlayerInputHandler.cs**: גשר למערכת הקלט (Input System). יורה אירועים (Events) אליהם ה-PlayerController מאזין.
* **Breakable.cs**: מערכת עצמאית להשמדת אובייקטים המטפלת ביצירת סאונד ואפקט חלקיקים מיד לפני ה-`Destroy`.

## 3. מערכת הקונכיות (Shell System)
מערכת מודולרית (`Shell.cs`) בעלת 4 מצבים (OnGround, OnBack, InUse, Thrown). בעת איסוף, הפיזיקה של הקונכייה מנוטרלת והיא הופכת לילד של השחקן, עם סנכרון מיקום וזווית מדויקים. כאשר מושלכת, היא טסה קדימה בפיזיקה רגילה וממתינה לעצירה כדי לחזור למצב איסוף.

**הקונכיות הקיימות:**
1. **TunaCan (כדור אוגר):** מכבה את הקוליידרים והפיזיקה של השחקן. הפחית מופעלת ככדור פיזיקלי טהור הנשלט בעזרת מומנט סיבוב (`AddTorque`) וחיכוך אורגני בלבד. כולל יכולת קפיצה קטנה (`jumpForce`) וזיהוי קרקע כדי לאפשר בלימה בעזרת `angularDamping`.
2. **ArmorShell (שריון כבד):** מעניקה לשחקן יכולת דחיפה אינסופית (`Mathf.Infinity`) ומאפשרת שליטה על מהירותו דרך סליידר `speedMultiplier` פשוט. במצב `InUse` (לחיצה על רווח), הסרטן מתחבא בתוך השריון (המיקום הוויזואלי של הקונכייה משתנה כדי לכסות אותו), והופך לחסין ומוכן למעיכה. במצב זה, נפילה על אובייקטים בשכבת ה-`crushLayer` תגרום להריסתם.
3. **SpringShell (קפיץ):** מעניקה קפיצה חזקה ויחידה (`AddForce.Impulse`) עם Cooldown. תומכת בהפעלה מהאוויר (Double Jump) בהתאם להגדרה.
4. **SprayCan (יכולת Dash):** מזנקת קדימה בזווית מחושבת. משתמשת בכוח פיזיקלי טהור (`AddForce` עם `Impulse` מתוך ה-`FixedUpdate`) כדי להשתלב בצורה חלקה עם מנוע הפיזיקה ולאפשר מעבר נקי דרך במות חד-כיווניות (One-Way Platforms).

## 4. סביבה ופאזלים
* **Movable.cs**: אובייקט הניתן לדחיפה. ננעל במקום (FreezePositionX) אם השחקן מנסה לדחוף אותו ללא המסה/השריון המתאימים.
* **PipeTeleporter.cs**: צינורות השתגרות לשחקן. שואבים אותו באנימציית Lerp ופולטים אותו בצינור היעד. (כרגע נדרש להשלים נעילת קלט במהלך האנימציה).
